Menu Nav on Small Screens

The category bar overflows at ~952px and it's not obvious it scrolls. Which approach do you prefer?

A: Arrow Buttons + Enhanced Fade

Add clickable arrow buttons on the edges when content overflows. Wider, more visible fade gradients. Clear visual signal that there's more content.

Pros

  • Immediately obvious there's more content
  • Clickable — works for non-touch users too
  • Minimal layout change

Cons

  • Arrows take horizontal space
  • Extra JS for click-to-scroll

B: Multi-Row Wrap

Allow categories to wrap onto multiple rows on smaller screens. All categories visible at once — no scrolling needed.

Pros

  • All categories visible at once
  • No scrolling interaction needed
  • Pure CSS solution

Cons

  • Takes more vertical space (sticky nav grows taller)
  • Can look cluttered with many categories
  • Active underline less clear in wrapped layout

C: Pill Chips + Scroll Indicator

Restyle categories as pill-shaped chips (common mobile pattern). Add a small scroll progress bar or dot indicator below to signal scrollability.

Pros

  • Familiar mobile pattern (users expect to swipe pills)
  • Scroll indicator makes overflow obvious
  • Active state very clear (filled pill)

Cons

  • Bigger visual change from current design
  • Pills take slightly more horizontal space
  • Progress indicator adds a row of visual noise
