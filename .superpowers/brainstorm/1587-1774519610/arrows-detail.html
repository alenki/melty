Design Details

Arrow Buttons

  • 28×28px circular, subtle background
  • Positioned inside wider 48px fade zone
  • Appear/disappear based on scroll position
  • Click scrolls ~200px with smooth animation
  • Hover: slightly darker background
  • Hidden on mobile (<480px) — touch swipe is natural there

Fade Gradients

  • Widened from 32px → 48px
  • Gradient: solid 40% → transparent
  • Covers partially-visible text (more obvious cutoff)
  • Existing overflow detection logic reused
  • Smooth opacity transition preserved
